# Prism Run — Android release downloads

This repository exists to host a **public, directly-downloadable copy of the signed
Prism Run Android app** (`com.thelazydevs.prismrun`), for merchant and payment
verification purposes — BillDesk's merchant onboarding asks for a *Mobile App APK URL*.

Prism Run is a 3-lane endless runner for Android. The main source repository is private;
this repository carries only signed release build artifacts.
